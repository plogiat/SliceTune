# SliceTune 0.1 — Tokyo Sunset Preview

Многодорожечный аудиоредактор для Windows 10/11 x64 с русским и английским интерфейсами.

Записывайте голос, импортируйте аудио и видео, обрезайте и соединяйте клипы, меняйте скорость и тон, применяйте эффекты и экспортируйте WAV, MP3, FLAC или OGG. Сохраняйте переносимые проекты со всеми исходниками.

- **Setup-x64.exe** — установщик с выбором папки и ярлыком.
- **Windows-x64.zip** — распакуйте целиком и запустите SliceTune.exe.

Это предварительная версия. Коррекция вокала экспериментальная, рассчитана на сольную запись; не является обработкой в реальном времени. Экспорт ограничен 30 минутами, размер проекта — 512 МБ. Запись идёт по очереди с одного выбранного микрофона. Сборки пока без цифровой подписи издателя.

Multitrack audio editor for Windows 10/11 x64. Record, edit, mix, process and convert audio; extract audio from video; save portable projects. Russian / English UI. Experimental offline monophonic vocal correction. Unsigned preview builds.
